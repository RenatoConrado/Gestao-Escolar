# Sistema de Gestão Escolar Municipal - Protótipo de Usabilidade

Este projeto consiste na implementação de um protótipo de Sistema de Gestão Escolar desenvolvido como objeto de estudo para um Trabalho de Conclusão de Curso (TCC) focado em Usabilidade.

O sistema é executado em um ambiente de hardware embarcado de baixo custo (Orange Pi), atuando como servidor central na rede local da escola e permitindo que microcomputadores da rede acessem a interface web via IP local.
